# notebooks

실험 탐색용 notebook을 둘 위치이다.

원칙:

- 대용량 이미지, 생성 결과, checkpoint를 notebook에 포함하지 않는다.
- 실제 결과 수치는 실험 완료 후 근거와 함께 기록한다.
- 재현 가능한 코드는 가능하면 `src/`로 옮긴다.
- `.ipynb_checkpoints/`는 커밋하지 않는다.

향후 notebook 후보:

- baseline 결과 샘플 검토
- fit-aware feature 분포 확인
- pseudo label과 gold label 비교
- overlay visualization 프로토타입
